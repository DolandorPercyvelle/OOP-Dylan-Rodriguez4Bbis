# LAB7.1

## Instalar dependencias

Desde la raíz del repositorio, instala los paquetes con el mismo lanzador de Python que usarás para iniciar la aplicación:

```powershell
py -m pip install -r LAB7.1/requirements.txt
```

## Iniciar la aplicación

Desde la raíz del repositorio:

```powershell
py LAB7.1/main.py
```
